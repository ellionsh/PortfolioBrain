你的资产，需要一个会思考的大脑。
PortfolioBrain 是一个智能个人资产管理系统，基于 MySQL + DeepSeek Agent， 支持银行存款、理财、保险、多账户、多币种，并能自动分析现金流、风险与期限结构。

总资产：¥ 3,250,000

未来 6 个月净现金流：¥ 128,000

美元敞口：$ 42,000

核心特性
PortfolioBrain 不是记账本，而是一个真正的资产管理中枢。

多资产 · 多账户 · 多币种

支持银行存款、理财产品、保险、股票、基金等。

现金流引擎

自动生成存款利息、理财付息、保险缴费等现金流。

DeepSeek Agent

自动写 SQL、查库、执行买卖、解释结果。

系统架构
数据层、逻辑层、AI 层、UI 层清晰分离，易扩展。
User
 ├─ Web / Mobile / CLI
 └─ DeepSeek Agent
      ├─ SQL Skill → MySQL（12 张表）
      └─ Operation Skill → 资产操作层

Data Layer: MySQL + 视图
Logic Layer: AssetOperator + CashflowEngine
AI Layer: DeepSeek Chat + Tool Calling
UI Layer: Streamlit Dashboard + Flutter App + Web
界面预览

移动端

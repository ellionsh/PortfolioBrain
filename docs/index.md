# PortfolioBrain

智能个人资产管理系统（AI + MySQL + DeepSeek Agent）。

PortfolioBrain 旨在帮助个人管理多账户、多资产、多币种的资产组合，
并通过 DeepSeek Agent 实现自然语言查询、自动分析、自动操作。

## 功能特性

- 多资产：银行存款、理财、保险、股票、基金
- 多账户：银行、券商、保险公司
- 多币种：CNY / USD / HKD / EUR
- 自动现金流引擎
- DeepSeek Agent（自动写 SQL + 自动操作）
- Dashboard 可视化
- Flutter 移动端
- 自动任务系统（净值更新 + 到期提醒）
- 完整 REST API
